# 🍎 Питание: курс для Миланы

Мини-сайт про здоровое питание для подростка: 14 дней — 14 тем с видео с YouTube, мини-квизами и прогрессом (сохраняется в браузере через localStorage).

**Что внутри:**
- 🚦 База: что можно есть каждый день, что иногда, а что — как можно реже
- 🍔 Что будет, если питаться только фастфудом и сладким
- 📅 14 дней: каждый день — тема, встроенное видео, факт дня и вопрос для самопроверки

Один файл `index.html`, без сборки и зависимостей. Хостится на GitHub Pages.

Видео принадлежат их авторам на YouTube и встроены через стандартный плеер (youtube-nocookie).
